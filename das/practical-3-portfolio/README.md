# Practical 3: Personal Developer Portfolio

**Title:** Develop a Personal Portfolio Website with Modern CSS  
**Technology:** HTML5, CSS3, and Vanilla JavaScript  
**Theme:** Professional White, Black, and Electric Blue Accents  
**Student Developer:** Yash Gowardhan (B.Tech IT, 3rd Year)

---

## 📖 Overview
A modern developer portfolio representing Yash Gowardhan (B.Tech IT, SVPCET Nagpur). Built with clean typographic rhythm, subtle scroll-reveal animations, responsive layouts, and accessible client-side form validation.

## 📄 Pages Included
1. **Home (`index.html`):** Complete single-page portfolio with smooth anchor scrolling and dynamic header.
2. **About (`about.html`):** Academic biography, college background, and specialization focus.
3. **Skills (`skills.html`):** Technical matrix across frontend, backend, database, and system design.
4. **Projects (`projects.html`):** Engineering project cards with technology pills and links.
5. **Contact (`contact.html`):** Form interface with client-side validation logic.

## 🛠️ Key JavaScript Features
- **Mobile Hamburger Drawer:** Accessible toggle with focus lock and overlay dismissal.
- **Scroll Reveal Animations:** IntersectionObserver API-driven element appearance.
- **Client-Side Form Validation:** Real-time email syntax check, length boundaries, and non-blocking honest submission feedback (no mock transmission claim).
- **Back-to-Top Button:** Scroll-position-aware floating button.

## 🚀 How to Run
```bash
start index.html
```
