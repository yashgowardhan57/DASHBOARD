Express.js + EJS Server Guide

Practical 5 is built with an Express.js backend and EJS template engine supporting reusable partials (header.ejs, footer.ejs, news-card.ejs).

# Run the EJS backend server locally:
cd backend/services/practical-5-news-portal
npm install
npm start

# Server starts on port 3002:
http://localhost:3002/

When this standalone portal is open, articles can be read in full fidelity without any server dependency.
