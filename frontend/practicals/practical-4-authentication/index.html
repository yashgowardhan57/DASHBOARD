Architecture & Features

PostgreSQL Database: Unique email constraint, auto-created users table
Bcrypt Password Hashing: 12 salt rounds, no plaintext storage
Session Security: connect-pg-simple session store with HttpOnly cookies
Protected Route: /dashboard requires active authenticated session

How to Run the Server

# 1. Navigate to directory and install dependencies
cd practical-4-authentication
npm install

# 2. Configure .env with your PostgreSQL credentials
copy .env.example .env

# 3. Start the Express server on port 3001
npm start
