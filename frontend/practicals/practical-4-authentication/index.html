Live PostgreSQL & Express Server Guide

This practical includes a complete Node.js + Express + PostgreSQL backend. To run the full-stack server locally:

# 1. From workspace root, start the auth server
cd backend/services/practical-4-authentication
npm install

# 2. Configure database credentials
copy .env.example .env

# 3. Start the server (Port 3001)
npm start

When started, the page will automatically detect the server and connect with live database persistence.
